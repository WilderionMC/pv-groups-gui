# PV Groups GUI

Аддон добавляет клиентский интерфейс для [pv-addon-groups](https://github.com/plasmoapp/pv-addon-groups).
Игрок может просматривать и создавать голосовые группы, вступать в них и управлять участниками.

Клиент использует `GuiScreen`, `ScreenWrapper`, `Button`, `TextFieldWidget` и `AbstractScrollbar`
из самого Plasmo Voice. Новые сборки не требуют owo-lib. Формы и списки находятся в контейнере
с прокруткой и обрезкой содержимого, а ширина панели зависит от размера окна.

## Поддерживаемые версии

Новая клиентская матрица повторяет опубликованные стабильные сборки **Plasmo Voice 2.1.17**.

Общие переводы и иконка находятся в `client-ui/src/main/resources`.

## Установка

На клиент установите Plasmo Voice 2.1.17 и клиентский JAR для своей версии Minecraft и загрузчика.
Также установите зависимости выбранной сборки Plasmo Voice.

На сервер или прокси установите универсальный `pv-addon-groups-gui-1.0.0.jar` рядом с
Plasmo Voice и `pv-addon-groups`. Если группы работают на прокси, bridge нужен на прокси.
Серверный JAR содержит точки входа для Paper/Folia, Velocity/BungeeCord и поддерживаемых модовых платформ.

## Использование

Клавиша **G** открывает интерфейс в игре. Назначение меняется в настройках горячих клавиш **Plasmo Voice**.
Аддон использует его API горячих клавиш на всех загрузчиках.

Интерфейс позволяет создавать, выбирать и покидать группы, вводить пароль, приглашать игроков,
исключать и блокировать участников, снимать блокировку и передавать владение. Настройки группы
позволяют менять название, пароль, постоянство и фильтр разрешений. Доступность действий зависит
от прав, переданных сервером; сервер повторно проверяет каждый запрос.

На панели группы действия подписаны; настройки, передача владения и удаление доступны через
«Управление». В форме создания права входа и сохранение пустой группы находятся в «Дополнительно».
Все настройки, включая снятие пароля и сброс прав входа, применяются только по «Сохранить изменения»;
«Отмена» отбрасывает черновик. Запросы сохранения выполняются последовательно: при ошибке оставшиеся
изменения не отправляются, но уже подтверждённые сервером изменения сохраняются.

Пароли скрыты по умолчанию; кнопка «Показать» временно открывает введённый текст.
Ошибки входа отображаются рядом с паролем, результаты действий — отдельно от прокручиваемого списка.
Выбранный игрок выделяется рамкой и подписывается перед действием; название закрытой группы
показывается в окне пароля. Фильтр групп ищет
по названию только на текущей странице; её номер остаётся видимым. Подтверждения называют действие,
группу или игрока и объясняют последствия передачи владения, удаления и блокировки.

Список групп использует компактные карточки: название сверху, головы участников и число игроков
снизу, кнопка входа справа. Пароль закрытой группы вводится в отдельном окне, поэтому форма входа
не уменьшает область списка. Для открытой группы кнопка сразу отправляет запрос на вступление.

Локализация следует выбранному языку Minecraft. Доступны русский, английский, испанский,
бразильский португальский, французский, немецкий, упрощённый китайский, японский, корейский и хинди.
Проверки сборки контролируют полноту ключей и соответствие форматных аргументов во всех переводах.

## Сборка и проверка

Для сборки нужен JDK 25 и доступ к репозиториям зависимостей. Общий код клиента и серверный bridge
компилируются в Java 8 bytecode. Во время игры используется Java, требуемая соответствующей версией Minecraft.

Собрать клиентскую матрицу, проверить совместимость с Plasmo Voice и собрать серверный JAR:

```powershell
.\gradlew.bat assembleArtifacts -PwithClient=true --no-daemon
```

Все 33 установочных JAR и `SHA256SUMS.txt` появятся в `build/artifacts/plasmo-ui/`.
При наличии локального `.local-test.json` команда также обновляет клиентский JAR во всех совместимых
профилях Modrinth и серверный bridge в отдельном тестовом сервере. Старые JAR сохраняются в резервной
папке. Без локального файла настройки команда только собирает артефакты. Публикации нет.

Собрать один клиент:

```powershell
.\gradlew.bat :client-ui:jar-fabric-26.3 -PwithClient=true --no-daemon
```

Проверить всю матрицу:

```powershell
.\gradlew.bat :client-ui:check -PwithClient=true --no-daemon
```

Проверка скачивает закреплённые официальные JAR Plasmo Voice и сверяет SHA-512.
Затем `tools/VerifyClientCompatibility.java` проверяет ссылки на классы, методы и поля для каждого клиента,
Java 8 bytecode, метаданные загрузчика и отсутствие owo и прямых ссылок на имена Minecraft.
Проверка также охватывает отражённые обращения к исполнителю клиентского потока и отрисовке голов игроков.
Проверка бинарной совместимости не заменяет запуск игры и визуальную проверку экранов.

Собрать только серверный JAR:

```powershell
.\gradlew.bat :dist-server:shadowJar --no-daemon
```

## Локальная проверка

Автотесты интерфейса на Fabric 26.2 запускаются отдельной командой:

```powershell
.\gradlew.bat :client-ui:runClientGameTest -PwithClient=true --no-daemon
```

Нужны JDK 25 и графическое окружение. Первый запуск скачивает ресурсы Minecraft.
Fabric Client GameTest создаёт временный мир и проверяет экраны Plasmo через ввод мышью и клавиатурой.
Ответы протокола задаются тестовыми данными, поэтому эти тесты не проверяют работу bridge на Paper
или обмен голосом. Профили Modrinth и отдельный сервер на рабочем столе не используются.

Сценарии охватывают открытие по G, создание и вход с паролем, права кнопок, обновление участников, приглашения,
передачу владения, модерацию, подтверждение удаления и выхода, прокрутку и страницы списка.
Отдельно проверяются сохранение текста и фокуса при изменении окна, положение прокрутки после
обновления, очистка полей при сбросе настроек и наличие значков в шрифте Minecraft.
Повторное открытие приглашений проверяется после успешной отправки и обновления участников.
Скриншоты сохраняются в `client-ui/build/run/clientGameTest/screenshots/`, лог находится в
`client-ui/build/run/clientGameTest/logs/latest.log`. При следующем запуске Fabric очищает временную папку.
Скриншоты служат для просмотра результата, автоматического сравнения с эталонными картинками пока нет.

Код и зависимости из `src/gametest` не входят в установочные JAR. Обычный `:client-ui:check`
не запускает Minecraft; он по-прежнему выполняет проверки матрицы, размеров панели и регистрации G.

Для проверки остальных версий выбранные патчи записаны в `ui-test-matrix.json`: 15 линий
совместимости и 31 сочетание версии и загрузчика. Общие десять сценариев находятся в
`client-ui/src/uiTest`. Они используются и Fabric Client GameTest, и отдельным стендом для старых клиентов.

```powershell
python -m pip install --target build/matrix-deps minecraft-launcher-lib==8.0
.\gradlew.bat :client-ui:matrixTestAgent assembleArtifacts -PwithClient=true -PsyncLocalTest=false --no-daemon
python tools/run_ui_matrix.py
```

Стенд создаёт отдельные установки внутри `build/ui-matrix`, скачивает игру и загрузчики и запускает
клиенты по одному. Нужны JDK 8, 17, 21 и 25; на этом компьютере они берутся из кеша Gradle и
локальной установки JDK 25. Профили Modrinth и серверы на рабочем столе не используются.
Список запусков можно посмотреть через `--list`, выбрать один через `--targets fabric-26.2`.

В этих клиентах проверяются отрисовка и обработчики мыши и клавиатуры Plasmo. Ответы протокола
задаются тестовыми данными, а головы используют стандартные скины. Для G проверяется регистрация
кнопки; нажатие через игровой ввод и проверка отсутствующих символов шрифта дополнительно выполняются
в Fabric Client GameTest 26.2. Это разные уровни проверки, они записаны в отчёте.
Тестовый агент и общие сценарии не входят в установочные JAR.

Итоги сохраняются в `build/ui-matrix/report.json`, отдельные логи и скриншоты находятся в
`build/ui-matrix/runs/<загрузчик-версия>/`. Статус `prepared` означает только установку клиента;
успешный запуск UI имеет статус `passed` и десять выполненных сценариев.

На рабочем компьютере подготовлен отдельный Paper 26.2 сервер:
`%USERPROFILE%\Desktop\pv-groups-gui-test-server`. Адрес: `127.0.0.1:25567`, голосовой UDP-порт: `24467`.
Существующий сервер в `Desktop\server` не изменяется. Новый сервер запускается только по запросу пользователя,
через `start.ps1` в его папке. Сборка сама его не запускает и не перезапускает.

После запуска подключитесь совместимым профилем Modrinth и нажмите G. Проверьте создание, вступление,
пароль, приглашение второго игрока и выход, затем настройки и действия владельца. Измените размер окна
и масштаб интерфейса, проверьте длинные названия, прокрутку и сохранение введённого текста.

Замена JAR применяется после перезапуска клиента или сервера. Если работающий Minecraft блокирует файл,
установщик оставляет его нетронутым и сообщает о незавершённом обновлении. Повторная сборка повторяет установку.
Отчёт сохраняется в `build/local-test-sync.json`, резервные копии находятся в `%LOCALAPPDATA%\PVGroupsGui\backups`.

## Устройство проекта

| Модуль | Назначение |
|--------|------------|
| `protocol` | Бинарный протокол интерфейса и регистрация пакета |
| `bridge` | Общая серверная логика и адаптер к `pv-addon-groups` |
| `paper` | Серверный аддон |
| `velocity` | Аддон прокси |
| `dist-server` | Универсальный серверный JAR |
| `client` | Контроллер состояния и сетевой клиент |
| `client-ui` | Общий интерфейс Plasmo Voice, точки входа загрузчиков и клиентские JAR |

Клиент передаёт запросы через TCP Plasmo Voice, пакет `0x64`. Bridge на прокси отменяет пересылку
пакета на backend. Клиент получает `Hello`, `Browse`, `ActionResult` и `State`.
Регистрация пакета использует внутренний реестр `PacketTcpCodec`.

Bridge компилируется против `pv-addon-groups` 1.1.1. Права проверяются через зарегистрированный
`CommandHandler`, а не через отдельный список строк разрешений.
